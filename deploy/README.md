# QtFetcher (projet « Offre unique »)

Les appels d'offres publics français, ouverts ou à venir, où une entreprise ferait face à peu de concurrence.

Sources : DECP consolidées (data.gouv.fr), BOAMP (DILA), APProch via l'API Hémicycle. Licence Ouverte 2.0.
Les données sont un instantané du 14 novembre 2026 : les appels d'offres clos disparaissent de la liste.
