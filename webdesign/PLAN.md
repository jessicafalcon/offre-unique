as model for the styling

First, we have to include a new page in streamlit with the description of the company in a user-engaging way.

Very important: the data has to be conveyed as much as possible using little diagrams (emojis etc...): one of company size for instance, with different ones for different company sizes, one for activity sector, with clear categorization.
Also charts to show the previous contracts, sorted by clients, sizes etc...
A little diagram also needed to identify the differernt typologies of clients: regions, localities, iondividual buildings etc...
and also typologies of contracts (construction / it work etc...)
It really has to be as engaging and visual as possible, to give a positive image of the company to the user.

Then the main page that displays the open contracts that are interesting for the company, also using a lot of diagrams foir the type of clients, and the type of contract (cobstruction). Color scheme also for the size of the contract and the probability to be single bidder.
It should also be able to sort them, the whole thing beeing as engaging as possible.

Then we have the proof tab, which is already good, it will be further completed, but you need to update the design to match the rest of the website and make it engaging.
